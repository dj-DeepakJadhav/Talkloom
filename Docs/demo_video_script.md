# Talkloom demo script — verification-gated draft

For the Serverpod Build Something Real hackathon. This is a recording plan, not
a claim that a public demo or production AI session is available. Record only
after `LIVE-06` in [`fix_tickets_2026-10-06.md`](fix_tickets_2026-10-06.md)
passes. Replace every bracketed direction with behavior observed in the final
build; cut any step that fails during rehearsal.

## 0:00–0:25 — The save graveyard

Show a real saved German-learning video or document. Say: “I keep saving useful
German content, but rarely turn it into practice. Talkloom starts from the
content I already want to understand.”

## 0:25–1:00 — Add the learner's source

On a fresh test account, add the real source through the supported input mode.
Show preparation, then the honest result. If extraction fails, show the retry
or paste-transcript recovery; never substitute a fabricated transcript.

## 1:00–1:35 — Review what came from it

Open the source's Words and Grammar tabs. Pick one word and one grammar pattern;
show their definitions and exact source context. State the visible counts from
the screen. Do not claim exhaustive coverage unless source comparison supports
that claim.

## 1:35–2:25 — Use it in speaking

Start the contextual conversation and use one expression from the source. Show
the real voice or the tested text fallback. Explain the correction and retry
behavior. Do not show a mastery badge unless the evidence criteria and persisted
record have been independently verified.

## 2:25–2:50 — Show persistence and ownership

Return to My German and show the source-linked item. Sign into a second test
account and verify the first account's source and progress are not visible.

## 2:50–3:00 — Close

Say: “Talkloom turns the material I already save into a reason to speak. Built
with Flutter and Serverpod.” Show the actual public URL and repository only after
they resolve from a fresh browser.

No Nebius/NVIDIA, Tavily, Agent Reach, Qwen3-TTS, latency, learning-outcome,
formal CEFR, or cost claims belong in the recording unless the exact integration
and measured result have a reproducible test.
