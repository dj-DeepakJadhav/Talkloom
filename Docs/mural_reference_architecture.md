# Historical Mural reference

Mural was an architectural reference for readable voice conversations, gentle
correction and language-isolated records. It is no longer the visual design
contract for Talkloom. Do not replicate its screenshots, orb, Talk/Themes/Words
navigation, recall bars or BYOK interface.

The current contract is [Talkloom design specification](talkloom_design_specification.md).
Talkloom centers on the user's imported German content and its source context.
The original reference can be recovered from Git history.

Reference: https://github.com/Chuloo/mural

## Current visual references

The Mural repository remains historical context. The current visual direction
uses the reference image's broad color fields and quiet composition, then adds
Lucide's consistent outline icons and Astryx's composable, token-driven system:

- https://lucide.dev/
- https://github.com/facebook/astryx

Talkloom's differentiator is the action: a learner moves from their own source
to a German speaking turn quickly. Keep copy short, retain source context, and
use motion to confirm transitions rather than decorate the page.
